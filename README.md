# KidsPC — instaladores

Este repositório publica apenas os instaladores do KidsPC para Windows. O
código-fonte é privado.

- Baixar: <https://www.kidspc.com.br/download>
- Instalador mais recente: `KidsPC_Setup.exe` na [última release](https://github.com/overdrive-dev/silencio-no-pc/releases/latest)
- Cada release traz `SHA256SUMS.txt` para conferir a integridade dos arquivos.

O programa instalado verifica e aplica atualizações sozinho.
